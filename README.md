# Minesweeper (C + raylib)

Игра «Сапёр» на языке C с графикой на raylib. 

## Возможности
- Три уровня сложности: Beginner (9×9, 10 мин), Intermediate (16×16, 40), Expert (16×30, 99)
- Режимы: игрок, простой бот, продвинутый бот, «бот против бота»
- Таблица рекордов ("records.txt")
- Анимация взрывов

## Требования
- Компилятор GCC/Clang (C99 и выше)
- [raylib](https://www.raylib.com/) 4.x/5.x

## Структура
|     Файл       |               Назначение                 |
|----------------|------------------------------------------|
|   `game.c/h`   | поле, клетки, раскрытие, проверка победы |
|   `bot.c/h`    |            алгоритмы ботов               |
| `dual_bot.c/h` |         режим «бот против бота»          |
| `graphics.c/h` |               отрисовка                  |
| `records.c/h`  |                рекорды                   |
|    `main.c`    |          меню и игровой цикл             |
